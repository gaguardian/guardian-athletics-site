# Guardian Athletics Website

Initial one-page "Coming Soon" splash site for Guardian Athletics.

## Stack

- React 19
- Vite 8
- TypeScript
- Git / GitHub
- Cloudflare deployment planned

## Local development

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
```

The production files will be generated in `dist/`.
